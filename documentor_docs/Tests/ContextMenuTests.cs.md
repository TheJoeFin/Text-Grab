# Documentation: `Tests/ContextMenuTests.cs`

## Overview

The `ContextMenuTests` class contains unit tests written in C# using the xUnit testing framework. Its primary purpose is to verify the correctness and consistency of the Windows Registry shell key path strings generated by the `ContextMenuUtilities.GetShellKeyPath` method for various file extensions (such as `.png`, `.jpg`, and `.tiff`).

## How It Works

### Test Execution Flow

Each method in `ContextMenuTests` is decorated with xUnit's `[Fact]` attribute, marking it as a runnable unit test that takes no parameters.

When the test suite runs:
1. **Invocation:** The test runner executes each `[Fact]` method independently.
2. **Execution:** The method calls `ContextMenuUtilities.GetShellKeyPath(extension)` from the `Text_Grab.Utilities` namespace.
3. **Verification:** The test framework checks the resulting string against expected constants using xUnit assertions (`Assert.Equal`, `Assert.StartsWith`, `Assert.EndsWith`).
4. **Result:** If any assertion fails, the test runner flags the test as failed. Otherwise, the test passes.
