# Documentation: `Tests/ClipboardUtilitiesTests.cs`

## Overview

The `ClipboardUtilitiesTests.cs` file contains unit tests for the `ClipboardUtilities` class—specifically targeting the static method `ClipboardUtilities.ConvertHtmlToTabSeparated`. Located in the `Tests` namespace, this class uses the **xUnit** framework (`[Fact]` attributes and `Assert` assertions) to verify that HTML tables embedded within clipboard formatted text (such as `CF_HTML`) are correctly parsed into tab-separated text representations (`\t` for columns, `\n` for rows).

---

## Constants & Test Fixtures

The class defines two private string constants containing raw `CF_HTML` formatted strings used across the test suite:

### 1. `SampleCfHtml`
* **Description**: Simulates standard Windows Clipboard HTML format (`CF_HTML`) containing meta-headers (`Version`, `StartHTML`, `EndHTML`, `StartFragment`, `EndFragment`) and a standard `<table>` element with 3 rows and 3 columns (`Month`, `Int`, `Season`).

### 2. `ExtensionRegionTableCfHtml`
* **Description**: Simulates HTML generated by the Text Grab browser extension's Table mode (specifically output matching `toCleanHtmlTable`).
* **Content Details**: Contains standard HTML tags with `<br>` line breaks and encoded HTML entities (`&amp;`).

## Key Tested Behaviors & Test Cases

The test suite consists of **9 unit test methods**, each checking a specific HTML table conversion behavior or edge case in `ClipboardUtilities.ConvertHtmlToTabSeparated`.

## Detailed Method Descriptions

### 1. `ConvertHtmlToTabSeparated_ParsesBasicTable()`
* **Purpose**: Validates basic functionality by parsing `SampleCfHtml`.
* **Execution**: Passes `SampleCfHtml` to `ConvertHtmlToTabSeparated`.
* **Assertions**:
  * Line count equals `3`.
  * Line 1: `"Month\tInt\tSeason"`
  * Line 2: `"January\t1\tWinter"`
  * Line 3: `"February\t2\tWinter"`

### 2. `ConvertHtmlToTabSeparated_HandlesBrTag()`
* **Purpose**: Ensures `<br/>` line break tags within table cells do not produce new rows, but instead space-separated text within the cell.
* **Input**: `<td>4<br/>A</td><td>Spring</td>`
* **Assertion**: Output equals `"4 A\tSpring"`.

### 3. `ConvertHtmlToTabSeparated_ReturnsEmptyWhenNoTable()`
* **Purpose**: Ensures that HTML content lacking a `<table>` element results in an empty output.
* **Input**: `<p>No table here</p>`
* **Assertion**: Output is empty.

### 4. `ConvertHtmlToTabSeparated_DecodesHtmlEntities()`
* **Purpose**: Tests HTML entity decoding within cell values.
* **Input**: `<td>A &amp; B</td><td>&lt;tag&gt;</td>`
* **Assertion**: Output equals `"A & B\t<tag>"`.

### 5. `ConvertHtmlToTabSeparated_HandlesThElements()`
* **Purpose**: Verifies `<th>` tags are extracted identically to `<td>` tags.
* **Input**: Table containing `<tr><th>Name</th><th>Value</th></tr>` followed by standard `<td>` data.
* **Assertions**: Output generates 2 lines; header row matches `"Name\tValue"`.

### 6. `ConvertHtmlToTabSeparated_HandlesColspan()`
* **Purpose**: Verifies that horizontally merged cells duplicating values across columns are handled properly.
* **Input**: `<td colspan="2">Merged</td><td>Right</td>`
* **Assertion**: Output line matches `"Merged\tMerged\tRight"`.

### 7. `ConvertHtmlToTabSeparated_HandlesRowspan()`
* **Purpose**: Verifies that vertically merged cells duplicate their content across subsequent rows in the output text.
* **Input**: `<td rowspan="2">Tall</td>` in row 1 with standard cells in row 1 and row 2.
* **Assertions**:
  * Line 1 matches `"Tall\tTop"`
  * Line 2 matches `"Tall\tBottom"`

### 8. `ConvertHtmlToTabSeparated_DoesNotOverwriteRowspanWithColspan()`
* **Purpose**: Tests complex matrix layouts involving combinations of `rowspan` and `colspan`.
* **Input**:
  * Row 1: `<td>Left</td><td rowspan="2">Tall</td><td>Right</td>`
  * Row 2: `<td colspan="2">Merged</td>`
* **Assertions**:
  * Line 1 matches `"Left\tTall\tRight"`
  * Line 2 matches `"\tTall\tMerged\tMerged"`

### 9. `ConvertHtmlToTabSeparated_ParsesBrowserExtensionRegionTable()`
* **Purpose**: Pinning test for compatibility with the Text Grab Browser Extension (`text-grab://paste-spreadsheet` workflow).
* **Input**: `ExtensionRegionTableCfHtml` containing raw HTML with unclosed `<br>` tags and HTML entities inside `<td>` tags.
* **Assertions**:
  * Line 1: `"Product\tQty\tUnit price"`
  * Line 2: `"USB-C hub\t12\t$24.50"`
  * Line 3: `"Monitor arm\t5\t$130 & up"` (verifies `<br>` becomes space and `&amp;` becomes `&`).
