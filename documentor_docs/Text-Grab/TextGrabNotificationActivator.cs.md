# Technical Documentation: `TextGrabNotificationActivator.cs`

## Overview

The `TextGrabNotificationActivator` class serves as the COM-activated entry point for handling toast notification activations within the Text-Grab application. By inheriting from `NotificationActivator`, this class receives user interactions from Windows notifications and responds by launching the appropriate application window (`EditTextWindow`) on the UI thread when valid arguments are supplied.

---

## File Details

* **File Path:** `Text-Grab/TextGrabNotificationActivator.cs`
* **Namespace:** `Text_Grab`
* **Base Class:** `NotificationActivator`

## Class Attributes & COM Configuration

The class is decorated with several interop attributes required for Windows COM registration and callback execution:

```csharp
[ClassInterface(ClassInterfaceType.None)]
[ComSourceInterfaces(typeof(INotificationActivationCallback))]
[Guid("215d64d2-031c-33c7-96e3-61794cd1ee61"), ComVisible(true)]
```

* **`[ClassInterface(ClassInterfaceType.None)]`**: Indicates that no class interface is generated for COM, ensuring access is strictly controlled through explicitly exposed interfaces.
* **`[ComSourceInterfaces(typeof(INotificationActivationCallback))]`**: Identifies the COM source interface used to receive notification callback events.
* **`[Guid("215d64d2-031c-33c7-96e3-61794cd1ee61")]`**: Specifies the unique Class Identifier (CLSID) used by Windows to register and instantiate this COM server.
* **`[ComVisible(true)]`**: Exposes the class to COM callers outside the process.

## Key Components & Methods

### `OnActivated`

Overrides the `OnActivated` method defined in `NotificationActivator`. This method is automatically executed by the system when a user interacts with a notification generated by the application.

#### Method Signature
```csharp
public override void OnActivated(string invokedArgs, NotificationUserInput userInput, string appUserModelId)
```

#### Parameters
* **`invokedArgs`** (`string`): Argument string passed from the notification payload describing the action or context of the activation.
* **`userInput`** (`NotificationUserInput`): Contains input data entered by the user in the notification controls (if applicable).
* **`appUserModelId`** (`string`): The Application User Model ID (AUMID) associated with the notification context.

#### Implementation Logic

1. **Dispatcher Synchronization:**
   Uses `System.Windows.Application.Current.Dispatcher.Invoke` to ensure execution is synchronized with the primary WPF UI thread.

2. **Argument Validation & Action:**
   * Checks if `invokedArgs.Length != 0`.
   * **If `invokedArgs` is not empty:**
     * Instantiates a new `EditTextWindow` passing `invokedArgs` to its constructor:
       ```csharp
       EditTextWindow mtw = new(invokedArgs);
       ```
     * Displays the window by calling `mtw.Show()`.
     * Exits execution.
   * **If `invokedArgs` is empty:**
     * The method performs no action (e.g., when the top-level notification header is tapped without specific activation arguments).
