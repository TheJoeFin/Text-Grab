# Technical Documentation: `AutomationDiagnostics.cs`

**File Location:** `Text-Grab/Utilities/AutomationDiagnostics.cs`  
**Namespace:** `Text_Grab.Utilities`  
**Access Modifier:** `internal static`

---

## Overview

`AutomationDiagnostics` is an internal static utility class responsible for recording diagnostic logs, application lifecycle events, unhandled exception details, and WPF `Window` state changes. It persists diagnostic event logs and exception sentinel files to disk using JSON serialization, configured via an `AutomationProfile`.

---

## Key Components & Static Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `SyncRoot` | `readonly object` | Synchronization object used to lock critical sections during log writes and modifications to `TrackedWindows`. |
| `TrackedWindows` | `readonly HashSet<Window>` | Holds references to actively tracked `Window` instances to prevent duplicate registration and manage event subscription lifecycles. |
| `_profile` | `AutomationProfile?` | Holds the diagnostic configuration and file path definitions for logging. |

---

## Method Documentation

### 1. Application Initialization & Diagnostics Core

#### `Initialize(AutomationProfile profile)`
* **Scope:** `internal static void`
* **Parameters:**
  * `profile` (`AutomationProfile`): Diagnostic profile containing file paths and execution flags.
* **Functionality:**
  1. Stores the provided `AutomationProfile` instance into `_profile`.
  2. Ensures the diagnostic directory exists by calling `Directory.CreateDirectory(profile.DiagnosticsDirectory)`.
  3. Records a `"startup"` event with details containing `profile.RootPath` and `profile.AllowsSystemIntegration`.
  4. Registers a global class handler using `EventManager.RegisterClassHandler` for `FrameworkElement.LoadedEvent` on all `Window` types to invoke `WindowLoaded`.

---

#### `RecordReady(bool handledArgument, bool suppressDefaultLaunch)`
* **Scope:** `internal static void`
* **Parameters:**
  * `handledArgument` (`bool`): Indicates if startup arguments were processed.
  * `suppressDefaultLaunch` (`bool`): Indicates whether default launch actions are suppressed.
* **Functionality:**
  * Emits a `"ready"` diagnostic event containing `handledArgument` and `suppressDefaultLaunch`.

---

#### `RecordUnhandledException(string source, Exception exception)`
* **Scope:** `internal static void`
* **Parameters:**
  * `source` (`string`): The source or origin of the unhandled exception.
  * `exception` (`Exception`): The exception object caught by the application.
* **Functionality:**
  1. Calls `Record()` with the event name `"unhandled-exception"` and an anonymous object containing:
     * `source`
     * `exceptionType` (Full name of the exception type)
     * `Message`
     * `StackTrace`
  2. If `_profile` is non-null, writes a JSON file synchronously to `profile.FailureSentinelPath` using `File.WriteAllText`. The failure sentinel file records:
     * `timestampUtc` (`DateTimeOffset.UtcNow`)
     * `source`
     * `exceptionType`
     * `Message`

---

#### `Record(string eventName, object? details = null)`
* **Scope:** `internal static void`
* **Parameters:**
  * `eventName` (`string`): The name of the event being logged.
  * `details` (`object?`, optional): An optional payload containing contextual event details. Defaults to `null`.
* **Functionality:**
  1. Returns immediately if `_profile` is `null`.
  2. Constructs a JSON line using `JsonSerializer.Serialize` containing:
     * `timestampUtc`: Current UTC timestamp (`DateTimeOffset.UtcNow`).
     * `eventName`: Name of the event.
     * `details`: The contextual details provided.
  3. Thread-safely opens a `FileStream` in append mode (`FileMode.Append`, `FileAccess.Write`, `FileShare.ReadWrite`) targeted at `profile.DiagnosticsLogPath`.
  4. Appends the serialized JSON line to the log file.

---

### 2. Window Lifecycle Monitoring

#### `WindowLoaded(object sender, RoutedEventArgs args)`
* **Scope:** `private static void`
* **Description:** Handled automatically when a WPF `Window` triggers the `LoadedEvent`.
* **Functionality:**
  1. Validates that `sender` is a `Window`.
  2. Under a `SyncRoot` lock, adds the window to `TrackedWindows`. If already present, execution halts.
  3. Logs a `"window-loaded"` event with spatial and state details generated by `Describe(window)`.
  4. Attaches handlers to the window's `Activated`, `Deactivated`, and `Closed` events.

---

#### `WindowActivated(object? sender, EventArgs args)`
* **Scope:** `private static void`
* **Functionality:** Logs a `"window-activated"` event along with window details if `sender` is a `Window`.

---

#### `WindowDeactivated(object? sender, EventArgs args)`
* **Scope:** `private static void`
* **Functionality:** Logs a `"window-deactivated"` event along with window details if `sender` is a `Window`.

---

#### `WindowClosed(object? sender, EventArgs args)`
* **Scope:** `private static void`
* **Functionality:**
  1. Validates that `sender` is a `Window`.
  2. Unsubscribes from `Activated`, `Deactivated`, and `Closed` events.
  3. Under a `SyncRoot` lock, removes the window from `TrackedWindows`.
  4. Logs a `"window-closed"` event along with window details.

---

#### `Describe(Window window)`
* **Scope:** `private static object`
* **Parameters:** `window` (`Window`)
* **Returns:** An anonymous object representing window state:
  * `windowType` (`window.GetType().FullName`)
  * `Title`
  * `IsVisible`
  * `Left`
  * `Top`
  * `Width`
  * `Height`

## Logged Event Summary

| Event Name | Event Payload / Details | Trigger Point |
| :--- | :--- | :--- |
| `"startup"` | `RootPath`, `AllowsSystemIntegration` | `Initialize()` |
| `"ready"` | `handledArgument`, `suppressDefaultLaunch` | `RecordReady()` |
| `"unhandled-exception"` | `source`, `exceptionType`, `Message`, `StackTrace` | `RecordUnhandledException()` |
| `"window-loaded"` | Window state via `Describe(window)` | WPF Window `Loaded` event |
| `"window-activated"` | Window state via `Describe(window)` | WPF Window `Activated` event |
| `"window-deactivated"` | Window state via `Describe(window)` | WPF Window `Deactivated` event |
| `"window-closed"` | Window state via `Describe(window)` | WPF Window `Closed` event |
