# Technical Documentation: `SplitColumnWindow.xaml.cs`

## Overview

The `SplitColumnWindow` class (located in namespace `Text_Grab.Controls`) is a WPF fluent window control within the Text-Grab application. It provides an interactive user interface that allows users to split spreadsheet cell content into multiple columns using three distinct modes:
1. **Delimiter** (e.g., comma, tab, custom string)
2. **Regex Pattern** (raw regular expressions, saved regex patterns, or smart recognizers)
3. **Fixed Length** (splitting by character count from start or end)

The window features a live preview grid generated dynamically with a debounce timer as inputs change, and communicates results directly back to an owning `EditTextWindow`.

## Member Properties & Fields

### Properties
- **`SampleText`** (`string`, Default: `string.Empty`):  
  Holds the content of the sample cell shown in the read-only source text box. Set by the calling parent window before presenting `SplitColumnWindow`.

### Private Fields
- **`previewDebounceTimer`** (`DispatcherTimer`): Timer initialized to 200 ms to throttle preview render requests during user typing.
- **`lastSourceSelectedText`** (`string`): Caches the most recent non-empty text selection from `SourceTextBox`. Used by the pattern extractor feature.
- **`allPatternItems`** (`IReadOnlyList<PatternItem>`): Holds the complete set of available saved regex patterns and smart recognizers.

## Core Functionality & Features

### 1. Initialization and Lifecycle

- **`SplitColumnWindow()`**: Sets up component UI controls, configures `previewDebounceTimer` interval to 200 ms, and hooks the `Tick` event to `PreviewDebounceTimer_Tick`.
- **`Window_Loaded`**:
  - Sets `SourceTextBox.Text` to `SampleText`.
  - Populates the pattern picker via `LoadPatternPicker()`.
  - Generates the initial live preview (`UpdatePreview()`).
  - Sets keyboard focus to `DelimiterTextBox`.
- **`Window_Closed`**:
  - Stops `previewDebounceTimer`.
  - Clears `PreviewTextBox`.
- **`Window_KeyUp`**:
  - Listens for `Key.Escape` to close the window.

---

### 2. Command Execution & Integration with `EditTextWindow`

- **`Split_CanExecute`**: Evaluates `Owner is EditTextWindow`. Execution is permitted only when owned by an `EditTextWindow` instance.
- **`Split_Executed`**: Invokes `ApplySplit()` and calls `Close()`.
- **`Apply_Executed`**: Invokes `ApplySplit()` without closing the window.
- **`ApplySplit()`**: Calls `SplitSelectedSpreadsheetCells(...)` on the owning `EditTextWindow`, passing the `SplitColumnOptions` generated by `BuildOptions()`.

---

### 3. Splitting Modes & Option Building

The window configures options through `BuildOptions()`, returning a `SplitColumnOptions` instance based on active UI controls:

1. **Regex Mode (`RegexRadioButton.IsChecked`)**:
   - `Mode`: `SplitMode.Regex`
   - `PatternItem` & `Pattern`: Resolved using `ResolvePatternInput()`.
   - `IgnoreCase`: Set via `IgnoreCaseToggle.IsChecked`.
   - `SplitterHandling`: Computed via `GetSplitterHandling()`.

2. **Fixed Length Mode (`FixedLengthRadioButton.IsChecked`)**:
   - `Mode`: `SplitMode.FixedLength`
   - `Length`: Parsed from `LengthTextBox.Text` (guaranteed $\ge 0$).
   - `SplitFromEnd`: Set via `FromEndToggle.IsChecked`.

3. **Delimiter Mode (Default/Fallback)**:
   - `Mode`: `SplitMode.Delimiter`
   - `DelimiterText`: Read directly from `DelimiterTextBox.Text`.
   - `SplitterHandling`: Computed via `GetSplitterHandling()`.

#### Splitter Handling
Determined by `GetSplitterHandling()`:
- `SplitterLeftRadio.IsChecked` $\rightarrow$ `SplitterHandling.KeepLeft`
- `SplitterRightRadio.IsChecked` $\rightarrow$ `SplitterHandling.KeepRight`
- Otherwise $\rightarrow$ `SplitterHandling.Remove`

---

### 4. Pattern Management & Parsing

- **`LoadPatternPicker()`**:
  Retrieves patterns via `PatternItem.GetAll()`. Formats tokens via `TokenFor(...)`:
  - `PatternKind.SavedRegex` $\rightarrow$ `{p:PatternName}`
  - `PatternKind.Recognizer` $\rightarrow$ `{r:PatternName}`  
  Populates `PatternPickerBox.ItemsSource` with `InlinePickerItem` representations.

- **`ResolvePatternInput()`**:
  Reads serialized text from `PatternPickerBox`.
  - Matches against `PatternTokenRegex` (`^\{([pr]):(.+)\}$`).
  - If a token is detected, it matches the pattern name against `allPatternItems` and returns `(PatternItem, string.Empty)`.
  - If no token matches, it treats the input as a custom raw regular expression string and returns `(null, rawRegex)`.

- **`ExtractButton_Click()`**:
  Generates a regex pattern dynamically based on the current selection in `SourceTextBox` (or falls back to `lastSourceSelectedText`).
  - Utilizes `ExtractedPattern` logic to derive a pattern string.
  - Updates `PatternPickerBox` with the extracted serialized pattern.
  - Triggers debounced preview updates.

---

### 5. UI View State & Debounced Live Preview

- **`SplitModeRadioButton_Checked`**: Adjusts control visibility based on selection:
  - `DelimiterPanel`: Visible when `DelimiterRadioButton` is checked.
  - `RegexPanel`: Visible when `RegexRadioButton` is checked.
  - `FixedLengthPanel`: Visible when `FixedLengthRadioButton` is checked.
  - `SplitterHandlingPanel`: Hidden in Fixed Length mode; visible for Delimiter and Regex modes.

- **Debounced Preview Generation**:
  `SplitInputChanged`, `PatternInputChanged`, and pattern extraction restart `previewDebounceTimer`. When the timer ticks (`PreviewDebounceTimer_Tick`), it executes `UpdatePreview()`.

- **`UpdatePreview()`**:
  1. Executes `ColumnSplitUtilities.SplitCell(SampleText, BuildOptions())` to obtain output segments.
  2. Constructs a side-by-side text preview:
     - Header row with column labels (`Col 1`, `Col 2`, etc.).
     - Value row with newline characters sanitized to single spaces.
     - Separator standard: ` │ ` (vertical line with spaces).
     - Cell values longer than `PreviewMaxColumnWidth` (24 chars) are truncated with an ellipsis (`…`).
     - Spaces are padded to maintain fixed monospace alignment between header and value rows.
  3. Displays the resulting text grid inside `PreviewTextBox.Text`.
